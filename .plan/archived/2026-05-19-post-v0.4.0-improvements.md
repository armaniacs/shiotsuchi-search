In `core/src/db.rs`:

```rust
/// Execute WAL checkpoint(TRUNCATE) to flush WAL data into the main .db file.
/// Useful before file-level operations like rename or backup.
pub fn wal_checkpoint(&self) -> Result<(), DbError> {
    let conn = self.write_conn.borrow();
    conn.execute_batch("PRAGMA wal_checkpoint(TRUNCATE)")
        .map_err(DbError::Sqlite)
}
```
