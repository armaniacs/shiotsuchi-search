# RAG Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the existing `notes_fts`/`notes_meta` schema with a chunk-based RAG schema and wire up FTS-only search as the foundation for hybrid search.

**Architecture:** New `chunks` / `file_cache` / `fts_chunks` / `vec_chunks` tables replace the old two-table design. A new `chunker.rs` splits Markdown by headers/paragraphs. A new `embedder.rs` wraps `ort` + `tokenizers` for ONNX inference. The existing `indexer.rs`, `db.rs`, and `search.rs` are rewritten to use the new schema. The CLI gains `--mode`, `dredge`, and `setup` subcommands. Vector search is behind an optional embedder — FTS always works, vector gracefully degrades when the model is missing.

**Tech Stack:** `rusqlite` (bundled), `sqlite-vec` 0.1.x, `ort` 2.x, `tokenizers` 0.19.x, `ndarray` 0.15.x, `indicatif` 0.17.x, `tokio` 1.x (multi-thread), `rayon` 1.x

- `docs/superpowers/specs/2026-05-12-rag-implementation-pre-analysis.md`

**Implementation divergences from plan (all tasks):**
- `chunker.rs` is a single-chunk pass-through (not recursive header/paragraph splitter). Full chunking is a post-MVP step.
- `indexer.rs` uses `IndexConfig` (from `models.rs`) rather than the plan's `IndexerConfig` struct, and serial file processing rather than `rayon` batch parallelism (`RefCell<Connection>` is not `Sync`).
- `IndexResult` enum is defined in `indexer.rs` and re-exported via `lib.rs`; it was removed from `models.rs`.
- `extract_snippet` takes 3 parameters `(text, query, max_chars)`, not 4 as the plan draft implies.
- `DbError::Other(String)` was added to handle embedder/non-SQLite errors that aren't `Send+Sync`.
- `SearchResult` (legacy) was removed entirely; `ChunkSearchResult` is the only result type.
- `log.rs` output simplified to a flat path list via `db.list_cached_paths()` (no `list_all_metadata()`).
- `tide.rs` and `mcp/handler.rs` updated to use `stats.total_files` + `stats.total_chunks`.
- Task 8: `run_dive` retains `_notes_dir` / `_indexing_cfg` params for signature compatibility; `main.rs` call site unchanged.
- Task 9: `dredge` uses `--dry-run` / `--vacuum` flags (plan said `--analyze` / `--incremental`); `setup` uses `SHIOTSUCHI_EMBED_MODEL_PATH` env var (not `SHIOTSUCHI_MODEL_PATH`).
- Task 9: No SHA-256 model hash constant added (deferred until official model is downloaded).
- Task 10: `chart` / `scan` show fallback message but do not yet pass embedder to indexer (embedder stub always returns Err anyway).
- Task 5: `embedder.rs` ONNX inference pipeline implemented (`c6f9cd4`). Uses `ort::Session` with `RefCell` for interior mutability, `tokenizers::Tokenizer` for HuggingFace tokenization, mean pooling + L2 normalization for `last_hidden_state` output, and direct extraction for `sentence_embedding` output. ```rust
use crate::models::{Chunk, ChunkSearchResult, SearchMode, VaultStats};
use rusqlite::{params, Connection, OpenFlags, Result as SqliteResult};
use std::cell::RefCell;
use std::path::{Path, PathBuf};
use thiserror::Error;

#[derive(Error, Debug)]
pub enum DbError {
    #[error("SQLite error: {0}")]
    Sqlite(#[from] rusqlite::Error),
    #[error("Note not found: {0}")]
    NotFound(String),
    #[error("IO error: {0}")]
    Io(#[from] std::io::Error),
}

/// Manages the SQLite database — write connection for indexer,
/// read-only connection for search (WAL allows concurrent readers).
pub struct NoteDatabase {
    pub write_conn: RefCell<Connection>,
}

impl NoteDatabase {
    pub fn open<P: AsRef<Path>>(path: P) -> Result<Self, DbError> {
        let is_fresh = !path.as_ref().exists();
        let conn = Connection::open(&path)?;
        conn.pragma_update(None, "journal_mode", "WAL")?;
        let db = Self { write_conn: RefCell::new(conn) };
        db.migrate()?;
        #[cfg(unix)]
        if is_fresh {
            use std::os::unix::fs::PermissionsExt;
            let _ = std::fs::set_permissions(&path, std::fs::Permissions::from_mode(0o600));
            let base = path.as_ref().to_string_lossy();
            for suffix in ["-wal", "-shm"] {
                let companion = PathBuf::from(format!("{}{}", base, suffix));
                if companion.exists() {
                    let _ = std::fs::set_permissions(&companion, std::fs::Permissions::from_mode(0o600));
                }
            }
        }
        Ok(db)
    }

    pub fn open_in_memory() -> Result<Self, DbError> {
        let conn = Connection::open_in_memory()?;
        let db = Self { write_conn: RefCell::new(conn) };
        db.migrate()?;
        Ok(db)
    }

    /// Open a read-only connection to an existing DB (for MCP search handler).
    pub fn open_readonly<P: AsRef<Path>>(path: P) -> Result<Connection, DbError> {
        let conn = Connection::open_with_flags(path, OpenFlags::SQLITE_OPEN_READ_ONLY)?;
        Ok(conn)
    }

    fn migrate(&self) -> Result<(), DbError> {
        let conn = self.write_conn.borrow();
        let version: i64 = conn.query_row("PRAGMA user_version", [], |r| r.get(0)).unwrap_or(0);

        if version < 2 {
            // Drop v1 tables if present
            conn.execute_batch("
                DROP TABLE IF EXISTS notes_fts;
                DROP TABLE IF EXISTS notes_meta;
            ")?;
            self.create_schema(&conn)?;
            conn.execute_batch("PRAGMA user_version = 2")?;
        }
        Ok(())
    }

    fn create_schema(&self, conn: &Connection) -> SqliteResult<()> {
        conn.execute_batch("
            CREATE TABLE IF NOT EXISTS file_cache (
                path     TEXT PRIMARY KEY,
                hash     TEXT NOT NULL,
                mtime    INTEGER NOT NULL,
                model_id TEXT NOT NULL
            );

            CREATE TABLE IF NOT EXISTS chunks (
                id                INTEGER PRIMARY KEY,
                file_path         TEXT NOT NULL,
                chunk_index       INTEGER NOT NULL,
                parent_header     TEXT,
                content           TEXT NOT NULL,
                tokenized_content TEXT NOT NULL
            );
            CREATE INDEX IF NOT EXISTS idx_chunks_file_path ON chunks(file_path);

            CREATE VIRTUAL TABLE IF NOT EXISTS fts_chunks USING fts5(
                tokenized_content,
                content='chunks',
                content_rowid='id',
                tokenize='unicode61 remove_diacritics 0'
            );

            CREATE VIRTUAL TABLE IF NOT EXISTS vec_chunks USING vec0(
                chunk_id  INTEGER PRIMARY KEY,
                embedding FLOAT[1024]
            );
        ")?;
        Ok(())
    }

    /// Insert a batch of chunks for a file. Caller must have deleted old chunks first.
    pub fn insert_chunks(&self, chunks: &[Chunk]) -> Result<Vec<i64>, DbError> {
        let mut conn = self.write_conn.borrow_mut();
        let tx = conn.transaction()?;
        let mut ids = Vec::with_capacity(chunks.len());
        for chunk in chunks {
            tx.execute(
                "INSERT INTO chunks (file_path, chunk_index, parent_header, content, tokenized_content)
                 VALUES (?1,?2,?3,?4,?5)",
                params![chunk.file_path, chunk.chunk_index, chunk.parent_header, chunk.content, chunk.tokenized_content],
            )?;
            let id = tx.last_insert_rowid();
            // FTS insert (external content — fts_chunks maps to chunks.tokenized_content)
            tx.execute(
                "INSERT INTO fts_chunks(rowid, tokenized_content) VALUES (?1, ?2)",
                params![id, chunk.tokenized_content],
            )?;
            ids.push(id);
        }
        tx.commit()?;
        Ok(ids)
    }

    /// Insert embeddings for a batch of (chunk_id, embedding) pairs.
    pub fn insert_embeddings(&self, pairs: &[(i64, Vec<f32>)]) -> Result<(), DbError> {
        let mut conn = self.write_conn.borrow_mut();
        let tx = conn.transaction()?;
        for (chunk_id, embedding) in pairs {
            let blob: Vec<u8> = embedding.iter()
                .flat_map(|f| f.to_le_bytes())
                .collect();
            tx.execute(
                "INSERT INTO vec_chunks(chunk_id, embedding) VALUES (?1, ?2)",
                params![chunk_id, blob],
            )?;
        }
        tx.commit()?;
        Ok(())
    }

    /// Delete all chunks (and their FTS/vec entries) for a file path.
    /// fts_chunks is external content (content='chunks'), so normal DELETE works.
    pub fn delete_chunks_for_file(&self, file_path: &str) -> Result<(), DbError> {
        let mut conn = self.write_conn.borrow_mut();
        let tx = conn.transaction()?;

        let ids: Vec<i64> = {
            let mut stmt = tx.prepare("SELECT id FROM chunks WHERE file_path = ?1")?;
            stmt.query_map([file_path], |r| r.get(0))?
                .collect::<SqliteResult<Vec<_>>>()?
        };
        log::debug!("Deleting {} chunks for {}", ids.len(), file_path);

        for id in &ids {
            log::trace!("  deleting fts_chunks rowid={}", id);
            tx.execute("DELETE FROM fts_chunks WHERE rowid = ?1", [id])?;
            log::trace!("  deleting vec_chunks chunk_id={}", id);
            tx.execute("DELETE FROM vec_chunks WHERE chunk_id = ?1", [id])?;
        }

        log::debug!("  deleting from chunks table");
        tx.execute("DELETE FROM chunks WHERE file_path = ?1", [file_path])?;
        tx.commit()?;
        log::debug!("  committed delete for {}", file_path);
        Ok(())
    }

    /// Upsert file_cache entry.
    pub fn upsert_file_cache(
        &self,
        path: &str,
        hash: &str,
        mtime: i64,
        model_id: &str,
    ) -> Result<(), DbError> {
        self.write_conn.borrow().execute(
            "INSERT INTO file_cache (path, hash, mtime, model_id)
             VALUES (?1,?2,?3,?4)
             ON CONFLICT(path) DO UPDATE SET
                 hash=excluded.hash, mtime=excluded.mtime, model_id=excluded.model_id",
            params![path, hash, mtime, model_id],
        )?;
        Ok(())
    }

    /// Returns the stored hash for a file, or None if not cached.
    pub fn cached_hash(&self, path: &str) -> Result<Option<String>, DbError> {
        let conn = self.write_conn.borrow();
        match conn.query_row(
            "SELECT hash FROM file_cache WHERE path = ?1",
            [path],
            |r| r.get(0),
        ) {
            Ok(h) => Ok(Some(h)),
            Err(rusqlite::Error::QueryReturnedNoRows) => Ok(None),
            Err(e) => Err(DbError::Sqlite(e)),
        }
    }

    /// Delete file_cache entry for a file.
    pub fn delete_file_cache(&self, path: &str) -> Result<(), DbError> {
        self.write_conn.borrow().execute(
            "DELETE FROM file_cache WHERE path = ?1",
            [path],
        )?;
        Ok(())
    }

    /// FTS search on fts_chunks. Returns (chunk_id, score) pairs.
    pub fn fts_search(&self, fts5_query: &str, limit: usize) -> Result<Vec<(i64, f64)>, DbError> {
        let conn = self.write_conn.borrow();
        let mut stmt = conn.prepare(
            "SELECT rowid, rank FROM fts_chunks WHERE fts_chunks MATCH ?1 ORDER BY rank LIMIT ?2"
        )?;
        let rows = stmt.query_map(params![fts5_query, limit as i64], |r| {
            Ok((r.get::<_, i64>(0)?, r.get::<_, f64>(1)?))
        })?;
        rows.collect::<SqliteResult<Vec<_>>>().map_err(DbError::Sqlite)
    }

    /// Vector KNN search on vec_chunks. Returns (chunk_id, distance) pairs.
    pub fn vec_search(&self, embedding: &[f32], limit: usize) -> Result<Vec<(i64, f64)>, DbError> {
        let conn = self.write_conn.borrow();
        let blob: Vec<u8> = embedding.iter().flat_map(|f| f.to_le_bytes()).collect();
        let mut stmt = conn.prepare(
            "SELECT chunk_id, distance FROM vec_chunks
             WHERE embedding MATCH ?1 AND k = ?2
             ORDER BY distance"
        )?;
        let rows = stmt.query_map(params![blob, limit as i64], |r| {
            Ok((r.get::<_, i64>(0)?, r.get::<_, f64>(1)?))
        })?;
        rows.collect::<SqliteResult<Vec<_>>>().map_err(DbError::Sqlite)
    }

    /// Fetch chunks by ids, preserving order.
    pub fn get_chunks_by_ids(&self, ids: &[i64]) -> Result<Vec<Chunk>, DbError> {
        if ids.is_empty() { return Ok(vec![]); }
        let conn = self.write_conn.borrow();
        let placeholders: String = ids.iter().enumerate()
            .map(|(i, _)| format!("?{}", i + 1))
            .collect::<Vec<_>>()
            .join(",");
        let sql = format!(
            "SELECT id, file_path, chunk_index, parent_header, content, tokenized_content FROM chunks WHERE id IN ({})",
            placeholders
        );
        let mut stmt = conn.prepare(&sql)?;
        let params_vec: Vec<&dyn rusqlite::ToSql> = ids.iter()
            .map(|id| id as &dyn rusqlite::ToSql)
            .collect();
        let rows = stmt.query_map(params_vec.as_slice(), |r| {

        let conn = self.write_conn.borrow();
        let file_path: String = conn.query_row(
            "SELECT file_path FROM chunks WHERE id = ?1", [chunk_id], |r| r.get(0)
        ).map_err(|e| match e {
            rusqlite::Error::QueryReturnedNoRows => DbError::NotFound(chunk_id.to_string()),
            other => DbError::Sqlite(other),
        })?;
        let chunk_index: i64 = conn.query_row(
            "SELECT chunk_index FROM chunks WHERE id = ?1", [chunk_id], |r| r.get(0)
        )?;
        let w = window as i64;
        let mut stmt = conn.prepare(
            "SELECT id, file_path, chunk_index, parent_header, content, tokenized_content FROM chunks
             WHERE file_path = ?1 AND chunk_index BETWEEN ?2 AND ?3
             ORDER BY chunk_index"
        )?;

            Ok(Chunk {
                id: Some(r.get(0)?),
                file_path: r.get(1)?,
                chunk_index: r.get(2)?,
                parent_header: r.get(3)?,
                content: r.get(4)?,
                tokenized_content: r.get(5)?,

        })?;

    }

        let total_chunks: usize = conn.query_row("SELECT COUNT(*) FROM chunks", [], |r| r.get(0))?;
        let total_files: usize = conn.query_row("SELECT COUNT(*) FROM file_cache", [], |r| r.get(0))?;
        let vec_indexed: usize = conn.query_row("SELECT COUNT(*) FROM vec_chunks", [], |r| r.get(0))?;

use crate::models::Chunk;

const LEVEL2_SPLIT_THRESHOLD: usize = 1000; // chars

/// Split a Markdown document into chunks using recursive header/paragraph splitting.
/// Level 1: split on headers (#, ##, ###).
/// Level 2: if a section exceeds LEVEL2_SPLIT_THRESHOLD chars, split on blank lines.
pub fn chunk_markdown(file_path: &str, content: &str) -> Vec<Chunk> {
    if content.trim().is_empty() {
        return vec![Chunk {
            id: None,
            file_path: file_path.to_string(),
            chunk_index: 0,
            parent_header: None,
            content: String::new(),
            tokenized_content: String::new(),
        }];
    }

    let sections = split_by_headers(content);
    let mut chunks: Vec<Chunk> = Vec::new();

    for (header_stack, section_text) in sections {
        let parent_header = if header_stack.is_empty() {
            None
        } else {
            Some(header_stack.join(" > "))
        };

        if section_text.chars().count() > LEVEL2_SPLIT_THRESHOLD {
            // Level 2: split on blank lines (paragraph boundaries)
            let paragraphs = split_on_blank_lines(&section_text);
            for para in paragraphs {
                if !para.trim().is_empty() {
                    let idx = chunks.len() as i64;
                    chunks.push(Chunk {
                        id: None,
                        file_path: file_path.to_string(),
                        chunk_index: idx,
                        parent_header: parent_header.clone(),
                        content: para.trim().to_string(),
                        tokenized_content: String::new(),
                    });
                }
            }
        } else if !section_text.trim().is_empty() {
            let idx = chunks.len() as i64;
            chunks.push(Chunk {
                id: None,
                file_path: file_path.to_string(),
                chunk_index: idx,
                parent_header: parent_header.clone(),
                content: section_text.trim().to_string(),
                tokenized_content: String::new(),
            });
        }
    }

    if chunks.is_empty() {
        chunks.push(Chunk {
            id: None,
            file_path: file_path.to_string(),
            chunk_index: 0,
            parent_header: None,
            content: content.trim().to_string(),
            tokenized_content: String::new(),
        });
    }

    chunks
}

/// Split content on Markdown headers (#, ##, ###).
/// Returns (header_stack, section_body) for each section.
fn split_by_headers(content: &str) -> Vec<(Vec<String>, String)> {
    let mut sections: Vec<(Vec<String>, String)> = Vec::new();
    let mut current_headers: Vec<(usize, String)> = Vec::new(); // (level, text)
    let mut current_body = String::new();
    let mut in_code_block = false;

    for line in content.lines() {
        // Track fenced code blocks to avoid splitting inside them
        if line.starts_with("```") || line.starts_with("~~~") {
            in_code_block = !in_code_block;
            current_body.push_str(line);
            current_body.push('\n');
            continue;
        }
        if in_code_block {
            current_body.push_str(line);
            current_body.push('\n');
            continue;
        }

        if let Some(level) = header_level(line) {
            if !current_body.trim().is_empty() || !current_headers.is_empty() {
                let stack: Vec<String> = current_headers.iter().map(|(_, t)| t.clone()).collect();
                sections.push((stack, current_body.clone()));
                current_body.clear();
            }
            // Pop headers at same or deeper level
            current_headers.retain(|(l, _)| *l < level);
            let title = line.trim_start_matches('#').trim().to_string();
            current_headers.push((level, title));
        } else {
            current_body.push_str(line);
            current_body.push('\n');
        }
    }

    // Push final section
    let stack: Vec<String> = current_headers.iter().map(|(_, t)| t.clone()).collect();
    sections.push((stack, current_body));

    sections
}

fn header_level(line: &str) -> Option<usize> {
    if !line.starts_with('#') { return None; }
    let count = line.chars().take_while(|c| *c == '#').count();
    if count <= 3 && line.chars().nth(count) == Some(' ') {
        Some(count)
    } else {
        None
    }
}

fn split_on_blank_lines(text: &str) -> Vec<String> {
    let mut result = Vec::new();
    let mut current = String::new();
    for line in text.lines() {
        if line.trim().is_empty() && !current.trim().is_empty() {
            result.push(current.clone());
            current.clear();
        } else {
            current.push_str(line);
            current.push('\n');
        }
    }
    if !current.trim().is_empty() {
        result.push(current);
    }
    result
}

/// Configuration for the incremental vault indexer.
#[derive(Debug, Clone)]
pub struct IndexerConfig {
    /// Number of files to batch before committing. Default: 100.
    pub batch_size: usize,
    /// File extensions to index. Default: ["md", "markdown"].
    pub extensions: Vec<String>,
    /// Directory names to skip.
    pub exclude_dirs: Vec<String>,
    /// Skip directories starting with '.'.
    pub auto_exclude_hidden: bool,
}

impl Default for IndexerConfig {
    fn default() -> Self {
        Self {
            batch_size: 100,
            extensions: vec!["md".into(), "markdown".into()],
            exclude_dirs: vec!["node_modules".into()],
            auto_exclude_hidden: true,
        }
    }

/// Summary of an indexing run.
#[derive(Debug, Default)]
pub struct IndexReport {
    pub inserted: usize,
    pub updated: usize,
    pub skipped: usize,
    pub errors: usize,
    pub deleted: usize,
}

/// Walk `vault_dir`, chunk and index all Markdown files.
/// If `embedder` is None, only FTS is indexed (vec skipped).
pub fn index_vault(
    db: &NoteDatabase,
    tokenizer: &JapaneseTokenizer,
    embedder: Option<&Embedder>,
    vault_dir: &Path,
    cfg: &IndexerConfig,
) -> Result<IndexReport, DbError> {
    let model_id = embedder
        .map(|_| "qwen3-embedding-0.6b")
        .unwrap_or("none")
        .to_string();

    let mut report = IndexReport::default();
    let mut seen_paths: std::collections::HashSet<String> = std::collections::HashSet::new();

    let mut batch: Vec<(String, Vec<crate::models::Chunk>, String, i64)> = Vec::new();

    for entry in WalkDir::new(vault_dir)
        .follow_links(false)
        .into_iter()
        .filter_entry(|e| should_visit(e, cfg))
        .filter_map(|e| e.ok())
        .filter(|e| e.file_type().is_file())
        .filter(|e| has_target_extension(e.path(), &cfg.extensions))
    {
        let abs_path = entry.path();
        let rel_path = abs_path
            .strip_prefix(vault_dir)
            .unwrap_or(abs_path)
            .to_string_lossy()
            .replace('\\', "/");

        seen_paths.insert(rel_path.clone());

        let content = match fs::read_to_string(abs_path) {
            Ok(c) => c,
            Err(e) => {
                log::warn!("Failed to read {}: {}", rel_path, e);
                report.errors += 1;
                continue;
            }
        };

        let hash = sha256_hex(&content);
        let mtime = file_mtime(abs_path);

        // Hash-based skip
        match db.cached_hash(&rel_path)? {
            Some(cached) if cached == hash => {
                report.skipped += 1;
                continue;
            }
            _ => {}
        }

        let chunks = chunk_markdown(&rel_path, &content);
        batch.push((rel_path, chunks, hash, mtime));

        if batch.len() >= cfg.batch_size {
            flush_batch(db, embedder, &model_id, &mut batch, &mut report)?;
        }
    }

    if !batch.is_empty() {
        flush_batch(db, embedder, &model_id, &mut batch, &mut report)?;
    }

    // Remove stale files (deleted from vault)
    let cached = db.list_cached_paths()?;
    for path in cached {
        if !seen_paths.contains(&path) {
            if let Err(e) = db.delete_chunks_for_file(&path) {
                log::warn!("Failed to delete stale {}: {}", path, e);
            } else {
                db.delete_file_cache(&path)?;
                report.deleted += 1;
            }
        }
    }

    Ok(report)
}

fn flush_batch(
    db: &NoteDatabase,
    embedder: Option<&Embedder>,
    model_id: &str,
    batch: &mut Vec<(String, Vec<crate::models::Chunk>, String, i64)>,
    report: &mut IndexReport,
) -> Result<(), DbError> {
    for (rel_path, chunks, hash, mtime) in batch.drain(..) {
        let is_update = db.cached_hash(&rel_path)?.is_some();

        // Delete old chunks first
        db.delete_chunks_for_file(&rel_path)?;

        // Tokenize content for FTS5 indexing
        let mut tokenized_chunks = chunks;
        for chunk in &mut tokenized_chunks {
            chunk.tokenized_content = tokenizer.split(&chunk.content);
        }

        // Insert new chunks
        let ids = db.insert_chunks(&tokenized_chunks)?;

        // Embed and insert vectors if embedder available
        if let Some(emb) = embedder {
            let contents: Vec<&str> = tokenized_chunks.iter().map(|c| c.content.as_str()).collect();
            let embeddings = emb.embed_batch(&contents);
            let pairs: Vec<(i64, Vec<f32>)> = ids.iter().zip(embeddings.iter())
                .filter_map(|(id, res)| res.as_ref().ok().map(|e| (*id, e.clone())))
                .collect();
            if let Err(e) = db.insert_embeddings(&pairs) {
                log::warn!("Failed to insert embeddings: {}", e);
            }
        }

        db.upsert_file_cache(&rel_path, &hash, mtime, model_id)?;

        if is_update {
            report.updated += 1;
        } else {
            report.inserted += 1;
        }
    }
    Ok(())
}

fn should_visit(entry: &walkdir::DirEntry, cfg: &IndexerConfig) -> bool {
    if entry.file_type().is_dir() {
        let name = entry.file_name().to_string_lossy();
        if cfg.auto_exclude_hidden && name.starts_with('.') {
            return false;
        }
        if cfg.exclude_dirs.iter().any(|d| d == name.as_ref()) {
            return false;
        }
    }
    true
}

fn has_target_extension(path: &Path, extensions: &[String]) -> bool {
    path.extension()
        .and_then(|e| e.to_str())
        .map(|e| extensions.iter().any(|ext| ext.eq_ignore_ascii_case(e)))
        .unwrap_or(false)
}

fn sha256_hex(content: &str) -> String {
    let mut hasher = Sha256::new();
    hasher.update(content.as_bytes());
    hex::encode(hasher.finalize())
}

fn file_mtime(path: &Path) -> i64 {
    fs::metadata(path)
        .and_then(|m| m.modified())
        .map(|t| t.duration_since(SystemTime::UNIX_EPOCH).unwrap_or_default().as_secs() as i64)
        .unwrap_or(0)
}

#[derive(clap::ValueEnum, Clone, Debug)]
pub enum OutputFormat {
    Table,
    Json,
    JsonPretty,
}

/// CLI-side wrapper for SearchMode so core remains clap-independent.
#[derive(clap::ValueEnum, Clone, Debug, Default)]
pub enum CliSearchMode {
    #[default]
    Hybrid,
    Fts,
    Vec,
}

impl From<CliSearchMode> for SearchMode {
    fn from(mode: CliSearchMode) -> Self {
        match mode {
            CliSearchMode::Hybrid => SearchMode::Hybrid,
            CliSearchMode::Fts => SearchMode::Fts,
            CliSearchMode::Vec => SearchMode::Vec,
        }
    }
}

#[derive(Args, Debug)]
pub struct DiveArgs {
    /// Search query string.
    pub query: String,

    /// Search mode: fts (keyword), vec (semantic), hybrid (default).
    #[arg(long, value_enum, default_value_t = CliSearchMode::Hybrid)]
    pub mode: CliSearchMode,

    /// Maximum number of results.
    #[arg(long, default_value = "20")]
    pub limit: usize,

    /// Output format.
    #[arg(long, value_enum, default_value_t = OutputFormat::Table)]
    pub format: OutputFormat,

    /// Path to ONNX model file (overrides SHIOTSUCHI_MODEL_PATH and XDG default).
    #[arg(long)]
    pub model_path: Option<std::path::PathBuf>,
}

pub fn run_dive(
    args: &DiveArgs,
    db_path: &Path,
) -> Result<Vec<ChunkSearchResult>, Box<dyn std::error::Error>> {
    if args.query.trim().is_empty() {
        return Ok(vec![]);
    }

    let db = NoteDatabase::open(db_path)?;
    let tokenizer = get_tokenizer()?;

    let search_mode: SearchMode = args.mode.clone().into();

    let embedder = match resolve_model_path(args.model_path.as_deref()) {
        Some(p) => match Embedder::load(&p) {
            Ok(e) => Some(e),
            Err(e) => {
                eprintln!("[warn] Could not load embedder: {}. Using FTS only.", e);
                None
            }
        },
        None => {
            if matches!(search_mode, SearchMode::Vec | SearchMode::Hybrid) {
                eprintln!(
                    "[warn] モデルファイルが見つかりません。ベクトル検索は無効です。\n\
                     'shiotsuchi setup' を実行してモデルを配置してください。\n\
                     キーワード検索（FTS5）のみで動作します。"
                );
            }
            None
        }
    };

    let effective_mode = if embedder.is_none() {
        match search_mode {
            SearchMode::Vec => {
                return Err("Vector search requires a model. Run 'shiotsuchi setup'.".into());
            }
            _ => SearchMode::Fts,
        }
    } else {
        search_mode
    };

    let results = search(&db, &tokenizer, &args.query, args.limit, effective_mode, embedder.as_ref())?;
    Ok(results)
}

pub fn print_results(results: &[ChunkSearchResult], query: &str, format: &OutputFormat, elapsed: Duration) {
    match format {
        OutputFormat::Json => println!("{}", serde_json::to_string(results).unwrap_or_default()),
        OutputFormat::JsonPretty => println!("{}", serde_json::to_string_pretty(results).unwrap_or_default()),
        OutputFormat::Table => print_table(results, query, elapsed),
    }
}

fn print_table(results: &[ChunkSearchResult], query: &str, elapsed: Duration) {
    let sep = "━".repeat(78);
    println!("Results for \"{}\"", query);
    println!("{}", sep);
    for (i, r) in results.iter().enumerate() {
        let header = r.parent_header.as_deref().unwrap_or("(top level)");
        println!("  {}. {} > {}", i + 1, r.file_path, header);
        let snippet = extract_snippet(&r.content, query, 300);
        for line in snippet.lines() {
            println!("     {}", line);
        }
        println!("     [{:.4}]", r.score);
        println!();
    }
    println!("{}", sep);
    println!("{} results ({:.3}s)", results.len(), elapsed.as_secs_f64());
}

### 挑戦した仮定

| 仮定 | リスク | 発見 | 決定 |
|------|--------|------|------|
| `fts_chunks` は contentless で、特殊な DELETE 構文が必要 | **高** | スキーマ定義は `content='chunks', content_rowid='id'` なので **external content**。通常の `DELETE FROM fts_chunks WHERE rowid = ?` で正しく動作する。contentless 用の `INSERT ... VALUES('delete', ...)` は誤り。 | スキーマは external content のまま、DELETE コードを通常の `DELETE` に修正 |
| `unicode61` トークナイザーで生テキストを FTS5 登録しても日本語検索品質が維持される | **高** | 日本語はスペース区切りがないため `unicode61` は文字単位でインデックスし、現行の Vaporetto 形態素解析 + space-separated 登録と比較して再現率が大幅に低下する | `chunks` テーブルに `tokenized_content` 列を追加。FTS5 は `tokenized_content` を参照し、`content`（生テキスト）は人間向け出力に使用 |
| Qwen3-Embedding-0.6B の出力次元が 1024 | **高** | 公開情報では 1024。実際のモデルを確認済みではないが、ハードコードで進め後で検証する方針 | `FLOAT[1024]` と `EMBEDDING_DIM = 1024` をハードコード。モデル入手後に `sha256sum` で検証 |

### スキーマ変更のまとめ

```sql
-- chunks テーブル: tokenized_content 列を追加
CREATE TABLE IF NOT EXISTS chunks (
    id                INTEGER PRIMARY KEY,
    file_path         TEXT NOT NULL,
    chunk_index       INTEGER NOT NULL,
    parent_header     TEXT,
    content           TEXT NOT NULL,       -- 生テキスト（人間向け）
    tokenized_content TEXT NOT NULL        -- Vaporetto トークナイズ済み（FTS5 向け）
);

-- fts_chunks: 列名を tokenized_content に変更
CREATE VIRTUAL TABLE IF NOT EXISTS fts_chunks USING fts5(
    tokenized_content,
    content='chunks',
    content_rowid='id',
    tokenize='unicode61 remove_diacritics 0'
);
```
