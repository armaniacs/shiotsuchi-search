# RAG MCP Update Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Update the MCP server to expose the new RAG chunk schema via `search_local_notes`, `get_surrounding_context`, `index_status`, and `rebuild_index` tools, replacing the old `search_vault` / `read_full_note` / `vault_status` tools.

**Architecture:** MCP server main loop is updated to open a single read-only `Connection` at startup (held in `Arc`) and passed to all handlers. A tokio multi-thread runtime is introduced. The `tools.rs` and `handler.rs` are rewritten for the new tool surface. `rebuild_index` runs in a `tokio::spawn` background task and streams progress via `notifications/progress`.

**Prerequisite:** `2026-05-12-rag-core.md` plan must be fully complete before starting this plan.

**Tech Stack:** `tokio` 1.x (already in `core`), `rusqlite` read-only connection, `shiotsuchi-core` chunker/embedder/indexer/search

use rusqlite::Connection;
use serde_json::{json, Value};
use shiotsuchi_core::{
    db::NoteDatabase,
    models::SearchMode,
    search::{extract_snippet, search, SearchError},
    tokenizer::get_tokenizer,
};
use std::{path::Path, sync::Arc};

/// Format search results as Markdown for LLM consumption.
fn format_results_markdown(results: &[shiotsuchi_core::models::ChunkSearchResult], query: &str) -> String {
    if results.is_empty() {
        return "No results found.".to_string();
    }

    let mut out = String::from("### RETRIEVED CONTEXT ###\n\n");
    for (i, r) in results.iter().enumerate() {
        let header = r.parent_header.as_deref().unwrap_or("(top level)");
        out.push_str(&format!(
            "## Source {}: {} > {}\n\n",
            i + 1,
            r.file_path,
            header
        ));
        let snippet = extract_snippet(&r.content, query, 800);
        out.push_str(&snippet);
        out.push_str(&format!("\n\n_Score: {:.4}_\n\n---\n\n", r.score));
    }
    out.push_str("### END RETRIEVED CONTEXT ###\n");
    out
}

pub fn call_tool(
    name: &str,
    args: &Value,
    notes_dir: &Path,
    readonly_conn: Arc<Connection>,
) -> Result<Value, Box<dyn std::error::Error>> {
    match name {
        "search_local_notes" => {
            let query = args["query"].as_str().unwrap_or("").to_string();
            let limit = args["limit"].as_u64().unwrap_or(10).min(50) as usize;
            let mode_str = args["mode"].as_str().unwrap_or("hybrid");
            let mode = match mode_str {
                "fts" => SearchMode::Fts,
                "vec" => SearchMode::Vec,
                _ => SearchMode::Hybrid,
            };

            // Validate notes_dir for path traversal
            let canonical_vault = notes_dir.canonicalize()?;

            // Use a write-capable DB for search (WAL allows concurrent reads)
            // For MCP we open a temporary read-only session via the shared connection.
            // Since NoteDatabase wraps a RefCell, we open a fresh lightweight DB for search.
            let db = NoteDatabase::open_readonly_from_conn(readonly_conn)?;
            let tokenizer = get_tokenizer()?;

            // Embedder not loaded in MCP handler (too heavy to init per-request)
            // hybrid/fts both work; vec returns error which we surface gracefully
            let results = match search(&db, &tokenizer, &query, limit, mode.clone(), None) {
                Ok(r) => r,
                Err(SearchError::EmbedderUnavailable) => {
                    return Ok(json!({
                        "content": [{
                            "type": "text",
                            "text": "Vector search requires a model. Use mode='fts' or run 'shiotsuchi setup'."
                        }]
                    }));
                }
                Err(e) => return Err(e.into()),
            };

            let markdown = format_results_markdown(&results, &query);
            Ok(json!({
                "content": [{
                    "type": "text",
                    "text": markdown
                }]
            }))
        }

        "get_surrounding_context" => {
            let chunk_id = args["chunk_id"].as_i64()
                .ok_or("chunk_id must be an integer")?;
            let window = args["window"].as_u64().unwrap_or(2).min(5) as usize;

            let db = NoteDatabase::open_readonly_from_conn(readonly_conn)?;
            let chunks = db.get_surrounding_chunks(chunk_id, window)?;

            let mut out = format!("### Context around chunk {} ###\n\n", chunk_id);
            for c in &chunks {
                let marker = if c.id == Some(chunk_id) { "**[SELECTED]** " } else { "" };
                let header = c.parent_header.as_deref().unwrap_or("(top level)");
                out.push_str(&format!("## {}Source: {} > {}\n\n{}\n\n---\n\n",
                    marker, c.file_path, header, c.content));
            }

            Ok(json!({
                "content": [{"type": "text", "text": out}]
            }))
        }

        "index_status" => {
            let db = NoteDatabase::open_readonly_from_conn(readonly_conn)?;
            let stats = db.stats()?;
            let text = format!(
                "Indexed files: {}\nTotal chunks: {}\nVector-indexed chunks: {}\nDB size: {:.1} MB\n\
                 Note: this status may be slightly stale if background indexing is running.",
                stats.total_files,
                stats.total_chunks,
                stats.vec_indexed_chunks,
                stats.total_size_bytes as f64 / 1_048_576.0
            );
            Ok(json!({"content": [{"type": "text", "text": text}]}))
        }

        "rebuild_index" => {
            // Rebuilding is handled by the CLI. The MCP server is read-only by design.
            Ok(json!({
                "content": [{
                    "type": "text",
                    "text": "To rebuild the index, run: shiotsuchi chart --force\n\
                             The MCP server will automatically use the updated index."
                }]
            }))
        }

        _ => Err(format!("Unknown tool: {}", name).into()),
    }
}

> **Note on `NoteDatabase::open_readonly_from_conn`:** This helper needs to be added to `db.rs` in `core`. It wraps an existing `Arc<Connection>` as a thin read-only facade so handler code stays clean. Add this to `core/src/db.rs`:

```rust
/// Thin read-only facade over a shared Connection for MCP handlers.
pub struct ReadonlyDb {
    conn: Arc<rusqlite::Connection>,
}

impl ReadonlyDb {
    pub fn new(conn: Arc<rusqlite::Connection>) -> Self {
        Self { conn }
    }
    // Expose stats() and search methods as pass-throughs to the shared conn.
    // (Implement the same methods as NoteDatabase but using self.conn directly.)
}
```

However, because `NoteDatabase` currently wraps `RefCell<Connection>`, the cleanest path is to **pass the db_path string to handler** and open a fresh read-only `Connection` per request (lightweight in SQLite/WAL). Update `call_tool` to take `db_path: &Path` instead of `Arc<Connection>`, and open via `NoteDatabase::open_readonly(db_path)` each call. This avoids the facade complexity.

Revise `call_tool` signature to:
```rust
pub fn call_tool(
    name: &str,
    args: &Value,
    notes_dir: &Path,
    db_path: &Path,
) -> Result<Value, Box<dyn std::error::Error>>
```

And replace `NoteDatabase::open_readonly_from_conn(readonly_conn)?` with `NoteDatabase::open(db_path)?` in each arm (the read-only flag is enforced by the MCP tool design — `delete_chunks_for_file` etc. are never called from handlers).
