Features 特徴

⚡

Sub-second search サブ秒検索

SQLite FTS5 delivers fast full-text search across 10,000+ notes on spinning disk or SSD. SQLite FTS5により、1万ノート超でもHDD・SSDを問わず高速な全文検索を実現。

🇯🇵

Japanese-aware tokenization 日本語トークナイザー内蔵

Vaporetto tokenizer compiled into the binary — no separate runtime, no loading overhead. Vaporettoトークナイザーをバイナリに組み込み済み。別途ランタイム不要でそのまま動く。

🔗

Claude Desktop via MCP Claude Desktop MCP連携

Ask Claude to search your vault naturally. The MCP server exposes search, read, and stats tools. Claudeに自然言語でノートを検索させる。MCP経由で検索・全文取得・統計ツールを提供。

🔄

Incremental indexing 差分インデックス

SHA-256 hash tracking means only changed files are re-indexed. Re-runs are instant. SHA-256ハッシュで変更ファイルのみ再インデックス。2回目以降は瞬時に完了。

👀

Live file watcher ファイル監視モード

shiotsuchi scan watches your vault and re-indexes on every save, keeping search always current. shiotsuchi scanでvaultを監視し、保存のたびに自動で再インデックス。

🔒

Privacy-first プライバシー重視

Everything runs locally. No cloud, no telemetry. Config and DB files use 0600 permissions. 完全ローカル動作。クラウド不使用・テレメトリなし。設定・DBは0600パーミッション。

Installation インストール

Choose the method that suits you 用途に合わせて選んでください

A

cargo install cargo install 

cargo install shiotsuchi \
  shiotsuchi-mcp

Fastest. No git clone needed. Requires Rust 1.75+. Set SHIOTSUCHI_MODEL_PATH after install — see INSTALL.md. 最速。git clone 不要。Rust 1.75+ が必要。インストール後に SHIOTSUCHI_MODEL_PATH を設定 — INSTALL.ja.md 参照。

B

cargo install --git cargo install --git 

cargo install --git \
  https://github.com/armaniacs/\
  shiotsuchi-search \
  shiotsuchi shiotsuchi-mcp

Latest git HEAD. Same model requirement as option A. 最新の git HEAD を使用。モデルの設定手順は方法 A と同じ。

C

git + make install (recommended) git + make install （推奨） 

git clone https://github.com/\
  armaniacs/shiotsuchi-search.git
cd shiotsuchi-search
make install

Model is embedded at compile time. No extra env var needed. Installs to ~/.local/bin. モデルをコンパイル時に埋め込み。環境変数の設定不要。~/.local/bin にインストール。

Start searching 検索開始 

shiotsuchi init --notes-dir ~/Notes
shiotsuchi chart
shiotsuchi dive "your query"

See INSTALL.md for full details 詳細は INSTALL.ja.md を参照

MCP

Claude Desktop integration Claude Desktop との連携

Add the MCP server to Claude Desktop and ask Claude to search your vault in natural language. Three tools are available: search_vault, read_full_note, and vault_status. MCP サーバーを Claude Desktop に登録すると、自然言語でノートを検索できます。search_vault・read_full_note・vault_status の3つのツールが使えます。

  • ✓ "Search my notes for Q3 budget" 「Q3の予算についてノートを検索して」
  • ✓ "Summarize my recent photography notes" 「最近の写真関連メモを要約して」
  • ✓ Multiple vaults — one MCP server per vault 複数vault対応 — vaultごとに1プロセス
MCP setup guide → MCP セットアップガイド →
claude_desktop_config.json 
{
  "mcpServers": {
    "shiotsuchi": {
      "command": "shiotsuchi-mcp",
      "args": [
        "--config",
        "~/.config/shiotsuchi/config.toml"
      ]
    }
  }
}

Commands コマンド一覧

Command コマンド Description 説明
shiotsuchi init Create config file, scan vault for exclusion candidates 設定ファイル生成・除外候補のスキャン
shiotsuchi chart Index / re-index all Markdown files Markdownファイルをインデックス（差分更新）
shiotsuchi dive <query> Full-text AND search, returns paths + snippets 全文AND検索。パスとスニペットを返す
shiotsuchi scan Watch vault, auto re-index on file change ファイル監視・変更時に自動再インデックス
shiotsuchi tide Show vault statistics (note count, DB size, last indexed) vault統計（ノート数・DBサイズ・最終インデックス日時）
shiotsuchi log Show recent indexing history 最近のインデックス履歴を表示
shiotsuchi delete <path> Remove a note from the index (file is not deleted) インデックスからノートを削除（ファイルは残る）
